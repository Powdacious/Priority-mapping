Priority Matrix
---
There are so many ways to prioritize, this toold is a quick start to the prioritization conversation that your business needs a jump off point for.

- Product: Having an idea of value can help, reduce assumption by considering estimation based on resulting factors such as scale, ease of expansion and strategic impact

- Tech Leads: 

Let this excercise inform you just enough, then catelyze you into more detailed value judgments, like _Opportunity Gain_

>**Opportunity Gain = Net Value (Idea A) - Net Value (Best Alternative)**  
Where __Net Value (NV)__ is defined as:  
Net Value = (Estimated Stategic Impact) - (Implementation Effort)
>
